## Welcome page

- Studio name (heading): สตูดิโอจิบลิ
- Hero headline: โลกที่คุ้มค่าแก่การหลงใหล
- Overview paragraph: สตูดิโอจิบลิคือสตูดิโอแอนิเมชันญี่ปุ่นในตำนานผู้อยู่เบื้องหลังภาพยนตร์อันเป็นที่รักอย่างมิติวิญญาณมหัศจรรย์ โทโทโร่เพื่อนรัก และเจ้าหญิงจิตวิญญาณแห่งพงไพร อันเลื่องชื่อในด้านงานวาดด้วยมือ โลกที่รังสรรค์ขึ้นอย่างวิจิตร และการเล่าเรื่องที่กินใจ
- Secondary line under the overview: เลือกชมภาพยนตร์ของสตูดิโอและสำรวจรายละเอียดของแต่ละเรื่อง
- Button that opens the movies list: ดูภาพยนตร์

## Movies page

- Page heading: ภาพยนตร์สตูดิโอจิบลิ
- Page subtitle: สิบเรื่องเล่าแห่งการโบยบิน ผืนป่า และดินแดนอันไกลโพ้น
- Link back to the welcome page: กลับสู่หน้าต้อนรับ
- Error message when films fail to load: เราไม่สามารถโหลดภาพยนตร์ได้
- Retry button: ลองอีกครั้ง

## Film detail labels

- Director: ผู้กำกับ
- Release date: เข้าฉาย
- Runtime: ความยาว
- Runtime unit (shown after a number, e.g. 124 min): นาที
- Review score source: Rotten Tomatoes
- Trivia section: เกร็ดน่ารู้
